# CSC 411: Intermediate Machine Learning

Course materials for an interdisciplinary machine learning course I designed and teach at
San Francisco State University, in the [Promoting Inclusivity in Computing](https://pinc.sfsu.edu/)
minor.

The course takes students with no calculus, linear algebra, or machine learning background from
matrix multiplication to a transformer encoder written from scratch. Every operation is derived
and implemented by hand before a library does it.

## Samples

`public/` holds polished samples of the course's teaching artifacts:

- [`public/architecture-day.pdf`](public/architecture-day.pdf) — the architecture day handout,
  the single page that walks the whole encoder from tokens to logits.
- [`public/figures/`](public/figures/) — worked-example diagrams: one attention head computed by
  hand, the convolution window, one encoder block, and the feed-forward network.

## Notebooks

`notebooks/` holds the weekly lab sources, in teaching order. These are working materials rather
than polished samples; they are here so the course's structure is legible.
