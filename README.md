# CSC 411: Intermediate Machine Learning
Course materials for an interdisciplinary machine learning course I designed and teach at San Francisco State University, in the [Promoting Inclusivity in Computing](https://pinc.sfsu.edu/) minor.

The course takes students with no calculus, linear algebra, or machine learning background from matrix multiplication to a transformer encoder written from scratch.

## Status
The full text and exercises are being prepared as a public book and will be released under a permissive license after the current term.
