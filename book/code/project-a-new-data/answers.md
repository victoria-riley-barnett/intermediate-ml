# Answers: The method on data the course did not choose

1. The baseline: the rule that fits nothing and names the commonest training family, plus the model and split it is compared against. In the plate, 0.9646 is 564 genes ahead of the do-nothing rule and 12 genes behind the model it was derived from. Both are true, so the number is a verdict only against a named comparison.
2. Open leaks: grouping on the wrong field (for example the recording instead of the subject), and anything fitted before the cut (vocabulary, normalisation constant, component basis). The second is the one no overlap check catches.
3. Report a tie, or "no detectable difference". The spread is the size of training noise, so a difference inside it cannot be told from noise. The best seed is one draw from that noise, not a result.
4. A control has an expected value stated before the run and would come out differently if the explanation were wrong. A limit of the test is what that test could not have shown, whatever the project as a whole might show elsewhere.
5. Group on the subject, because recordings from one subject are not independent evidence. Grouping on the recording prints an overlap of zero while one subject's recordings still sit on both sides.
